# 架构决策记录

ADR 记录具有长期影响、存在合理替代方案的决策。ADR 一经接受不得重写历史；如果决策改变，新增 ADR 并将旧文档标记为 `Superseded`。

## 状态

- `Proposed`：待确认；
- `Accepted`：当前有效；
- `Superseded`：已被后续 ADR 替代；
- `Rejected`：讨论后未采用。
