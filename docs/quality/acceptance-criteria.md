# 质量与功能验收标准

状态：Accepted（阈值待基准集校准）
最后审阅：2026-07-30

## 验收层次

任务必须分别证明代码行为正确和图像效果没有退化。文件存在、程序未崩溃或输出是 PNG，都不足以证明提取质量达标。

## 功能不变量

| 验收 ID | 关联需求 | 验收结果 |
|---|---|---|
| AC-IO-001 | FR-INPUT-003 | 有效输入不会修改源文件。 |
| AC-IO-002 | FR-EXPORT-002 | 输出宽高等于修正 EXIF 方向后的输入宽高，除非用户明确选择缩放。 |
| AC-IO-003 | FR-EXPORT-001 | 输出为可解码的四通道 straight-alpha RGBA PNG。 |
| AC-ALPHA-001 | FR-EXT-002 | 内部 Alpha 为有限值且位于 `[0, 1]`。 |
| AC-ALPHA-002 | FR-EXPORT-004 | 预览背景不得写入输出 RGB/Alpha。 |
| AC-COR-001 | FR-COR-001、FR-COR-002、FR-COR-003、FR-COR-004 | 正负提示进入下一次交互分割，且提示支持撤销和重做。 |
| AC-ERR-001 | FR-INPUT-004、NFR-RECOVERY-001 | 单张图片处理失败不会破坏源文件；可恢复错误不会终止整个应用。 |

## 视觉验收维度

- 主物品轮廓完整，没有明显截断；
- 与主体相关且被选择的附件得到保留；
- 杯把、椅背等真实内部孔洞保持透明；
- 背景中不存在明显连通残留和大面积半透明雾；
- 硬边在 100% 预览下没有明显锯齿、连续白边或黑边；
- 在透明、白色和黑色背景上均检查结果；
- 新版本不得为了改善困难样本而显著破坏普通样本。

## 证据要求

- 纯算法和 I/O 行为由单元或集成测试证明；
- 真实 pipeline 至少运行 smoke 集；
- 影响 Alpha 的变更运行版本化评测集并保存摘要报告；
- 可见 UI 变更提供截图；
- 阈值、黄金结果或数据集变化需要独立说明，不能与算法变更静默混合。

具体数值阈值将在建立第一版人工确认的基准集后补充。

需求正文和优先级见[功能与非功能需求](../product/requirements.md)；本文只定义验收证据和结果判定，避免形成重复需求来源。
