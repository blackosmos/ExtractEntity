# 物品提取评测数据集

状态：Accepted（数据待建立）
最后审阅：2026-07-30

## 目的

评测集用于比较模型、发现视觉退化和证明质量提升。它不是训练集，也不能由当前被测算法自动生成 Ground Truth。

## 数据层级

- `smoke`：5–10 张小型代表图，验证 pipeline 和输出不变量；
- `common`：日常物品，包括电子产品、包装、鞋包、杯具、家具、工具、玩具和饰品；
- `difficult`：复杂背景、相近颜色、多个物品、反射、透明材质、细结构、内部孔洞、强阴影、贴边和低分辨率；
- `regression`：已经出现并修复的真实失败案例。

## 样本元数据

每个样本至少记录唯一 ID、集合、类别、特征标签、来源、许可、预期主体和人工备注。
“应保留附件”和“应透明孔洞”等通用特征使用规范标签（如 `detached-component` 和
`internal-hole`）表达，具体期望写入人工备注，避免与 manifest schema 形成两份事实。
来源不明或许可不清的图片不得提交仓库。

## 版本和存储

- 少量、低体积测试 fixture 可以进入普通 Git；
- 大型图片和 Ground Truth 使用 Git LFS 或独立的版本化本地数据包，具体方式在 M0 中决定；
- 仓库只提交 manifest、许可信息和可复现的评测脚本；
- `benchmarks/reports/` 的临时完整报告默认不提交，只保留经过挑选的摘要；
- 数据集变化必须更新版本和变更说明。

## 防止自证

- 禁止用当前模型结果直接替换黄金结果；
- 黄金结果变化必须经过人工复核并单独提交；
- 算法变更和黄金结果变更尽量分开；
- 失败样本修复后加入 regression，防止未来复发。
