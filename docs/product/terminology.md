# 项目术语

状态：Accepted
最后审阅：2026-07-30

| 术语 | 本项目中的含义 |
|---|---|
| 主体（Subject） | 用户希望保留的一个或多个物品及被明确选择的组成部分。 |
| 前景（Foreground） | 最终由 Alpha 保留的像素区域；不必等同于某个模型最显著的对象。 |
| Mask | 表示像素属于主体的二值结果或概率图。使用时必须说明是二值还是概率 Mask。 |
| Alpha Matte | 每像素连续透明度，内部统一表示范围为 `[0, 1]`。 |
| Trimap | 将像素分为确定背景、未知区域和确定前景的三值图。 |
| 候选（Candidate） | 某个模型和配置产生、尚未成为最终结果的一份主体 Mask 及元数据。 |
| 正向提示 | 用户指出必须属于主体的位置、区域或对象。 |
| 负向提示 | 用户指出必须属于背景的位置或区域。 |
| 原始尺寸 | 应用 EXIF 方向后的输入像素宽高，而不是文件中未经方向解释的矩阵宽高。 |
| 预览背景 | 仅用于检查透明结果的棋盘格或纯色，不属于输出图像。 |
| RGBA PNG | 包含红、绿、蓝和 Alpha 四通道的 PNG；项目默认导出 straight alpha。 |
| Ground Truth | 经过独立人工确认的评测参考，不由当前被测算法自行生成。 |
| Smoke 集 | 用于快速发现 pipeline 断裂的小型代表性评测子集。 |
| 回归样本 | 曾暴露真实缺陷、修复后保留以防问题复发的样本。 |

代码、任务和文档应优先使用本表术语。引入新的核心名词时先确认现有术语不能准确表达，再更新本表。
