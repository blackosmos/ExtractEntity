# 当前范围之外

状态：Accepted
最后审阅：2026-07-30

以下内容不属于当前产品范围。将其中任何项目移入范围前，必须更新产品文档、里程碑和必要的 ADR。

- 商业背景移除 API 或外部图片处理服务；
- 用户账号、多租户、权限、计费和公开部署；
- 云端图片存储、遥测和分享链接；
- 手机应用、浏览器扩展和设计软件插件；
- 视频、摄像头实时抠图和直播处理；
- 生成式模型重绘主体或补全原图外内容；
- 毛发专项优化和人像美化；
- 保证从单张图片物理正确地恢复所有透明物体；
- 第一版中的大规模批处理、独立阴影图层和复杂项目管理。

不在范围内不等于永远不做；它表示 AI 不得在当前任务中顺便实现。
