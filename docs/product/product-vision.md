# 产品愿景

状态：Accepted
最后审阅：2026-07-30

## 定义

ExtractEntity 是一个供项目所有者个人使用的本地图片工具。用户导入图片后，工具自动识别需要保留的物品，生成高质量连续 Alpha；自动结果不正确时，用户通过点击、框选或简单涂抹提供修正提示，最终导出透明 PNG。

## 目标用户

单一本地用户。项目不以公众发布、在线服务或商业化运营为目标。

## 核心价值

- 普通单物品图片尽可能一键完成；
- 主体完整，物品内部孔洞和相关附件得到合理保留；
- 硬边清晰，避免明显锯齿、背景残留、白边和黑边；
- 自动结果可被低成本地修正，而不是要求用户手工描边；
- 原图不离开本机，结果可以重复生成和验证。

## 成功条件

- 用户可完成“导入—检查—修正—保存”的闭环；
- 输出是修正 EXIF 方向后与原图同尺寸的 RGBA PNG；
- 用户可以在透明、白色和黑色背景下检查结果；
- 模型效果在版本化的物品评测集上可重复比较；
- 失败时提供可恢复操作，不静默输出明显错误结果；
- 新模型可以通过适配器替换，不要求重写 UI 和业务流程。

## 产品原则

1. 质量优先于处理速度。
2. 自动完成大部分工作，交互解决剩余歧义。
3. 以物品提取为主，不为毛发专项优化牺牲整体复杂度。
4. 不使用生成式模型重绘或猜测缺失的主体内容。
5. 产品结论以固定评测集和实际工作流为依据。

可追踪的强制行为由[功能与非功能需求](requirements.md)定义；本文只维护长期目标和产品原则。
