# 当前里程碑：M1 单图自动提取闭环

状态：Accepted
最后审阅：2026-07-30

## 目标

建立可从本地单张图片生成原始分辨率 straight-alpha RGBA PNG 的自动提取闭环。

## 包含范围

- JPEG、PNG、WebP 解码和 EXIF 规范化；
- 默认自动分割模型的来源、权重、许可与适配器；
- Alpha/RGBA 合成和 PNG 导出；
- 单图本地入口与真实 smoke 评测。

## 不包含

- Web UI；
- 多模型融合；
- SAM 2 交互修正；
- ViTMatte 全分辨率优化；
- 批处理；
- 商业 API。

## 退出标准

- 本地受支持图片可解码且源文件不变；
- 经许可核验的默认模型可生成主要物品候选；
- 输出是可回读、原始方向修正尺寸的 straight-alpha RGBA PNG；
- 单图入口具有可理解错误并默认不覆盖源文件；
- 固定 smoke 样本形成第一份真实质量证据。
