# 项目路线图

状态：Accepted
最后审阅：2026-07-30

路线图描述阶段顺序和退出方向，不是承诺日期，也不授权 AI 同时实现多个里程碑。当前允许实施的范围始终以[`current-milestone.md`](current-milestone.md)和 `Ready` 任务为准。

## M0：项目基础

建立文档基线、工程骨架、领域数据契约、测试工具、模型与许可证管理规则，以及最小 smoke 数据集。

## M1：单图自动提取闭环

通过一条可重复的命令或应用服务完成图片解码、默认分割模型、结果规范化、RGBA 合成和 PNG 导出。此阶段先证明 pipeline 正确，不开发完整交互界面。

## M2：Alpha Matting 与质量基线

接入 trimap 和 Matting，建立普通与困难物品评测集，比较 Matting 前后效果，并确定第一版定量阈值和人工验收流程。

## M3：本地 Web 基础界面

实现单图导入、阶段状态、原图/结果预览、背景切换、100% 检查和保存，让标准流程无需命令行。

## M4：交互式主体修正

接入交互分割，支持正负点击、框选、撤销和重做；涂抹是否进入本阶段由基础交互验证结果决定。

## M5：质量增强

根据 benchmark 证据决定是否增加候选模型、候选选择、全分辨率边缘切块、边缘颜色处理和自动质量告警。没有可测提升的复杂度不进入主流程。

## M6：个人批处理工作流

在单图质量稳定后增加任务队列、低置信度待确认、输出目录策略和设置持久化。项目历史、阴影独立层等能力仍需单独评估。

## 阶段推进规则

1. 当前里程碑退出标准满足后才能切换阶段；
2. 每一阶段开始前更新需求优先级、验收标准和任务拆分；
3. 阶段结束时执行仓库审计并只保留简短结果；
4. 路线图调整属于产品计划变化，不应夹带在普通实现任务中。
